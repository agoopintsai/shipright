## Question

Read the product's direction document. Is this requirement compatible with the current direction? If the product is in maintenance, being replaced, or being re-scoped, what does adding this cost the successor, and could it wait or be built elsewhere?

## Why it matters

Building on a system that is being retired is a double cost: the work now plus the migration work later. Starting work before the direction is settled is a common way to build something that is later withdrawn.
